# Memory Bloom 0.7.0 — edge-aware expansion and expiring evidence

- Date: 2026-10-23 14:02 America/Toronto
- Commit: [`0875e41`](https://github.com/nastajus/memory-bloom/commit/0875e41)
- Release: [`MemoryBloom.exe`](../releases/v0.7.0/MemoryBloom.exe)

## Reported problems

- Development restarts stole focus and left a flashing taskbar button.
- The rounded window had two visibly different corner curves.
- A right-aligned compact widget expanded off-screen when detailed mode opened.
- One ChatGPT tab accumulated several historical document titles under a PID.
- Six-minute-old associations still advertised 94–96% confidence.
- Firefox hosts and other app child processes needed memory-descending order.

## Implementation

- Added passive startup/restart behavior that records and restores the previously focused window.
- Unified the native window region with the broader 22-DIP panel radius and converted it using the current window DPI.
- Recorded the compact view's monitor half and expanded detailed mode inward while preserving the near edge.
- Tracked live titles per Firefox top-level window and normalized optional `— ChatGPT` suffixes.
- Suppressed superseded single-page-app titles until a newer recovery snapshot could distinguish navigation from a real tab switch.
- Added age-adjusted confidence and a two-minute current-placement expiry.
- Sorted child processes and Firefox tab hosts by private memory.

## Challenges and decisions

- The two-minute limit was intentionally conservative: it stopped an old high-confidence observation from masquerading as current. In this version, expiry moved the row to Unresolved; 0.8.0 retained it under the prior PID as explicitly historical evidence instead.
- Compact mode stores both left and right anchors so collapsing restores the user's chosen edge.
