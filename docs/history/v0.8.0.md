## Reported problems

- Refreshing many already-open Firefox tabs briefly created matches, but the yellow rows vanished about three minutes later.
- The Firefox dropdown showed Gmail, Calendar, several ChatGPT tabs, ActivityWatch, and New Tab, while Bloom showed only two duplicate links beneath one of thirteen candidates.
- The user needed to know whether data was deleted after minutes, why most refreshes were missed, and whether an extension could improve consistency.

## Root cause

- The two-minute rule expired the PID claim and moved it to Unresolved; it did not delete the title.
- Firefox's `recovery.jsonlz4` is delayed recovery state rather than a live tab API.
- The native top-level Firefox window title identifies only the foreground tab. Refreshing a background tab does not expose its title there.
- A recovery entry and live synthetic title could produce duplicate normalized rows.
- Firefox may reuse or change content processes. The WebExtensions Tabs API supplies tab/window identity and lifecycle events but does not expose a Windows PID.

## Implementation

- Added the optional local Firefox companion extension and native-messaging bridge.
- Added stable tab IDs, full catalog snapshots, titles, URLs, last-access times, active/hidden/discarded state, and events for activation, loading/reload, title/URL changes, create, close, replace, move, attach/detach, and window focus.
- Added a four-second event-driven PID-correlation window that can sample a background reload.
- Increased process activity sampling from 500 ms to 250 ms.
- Retained expired links under their last live PID as yellow **historical** evidence and separated current/historical counts.
- Deduplicated same-title recovery/live echoes when no stable companion ID exists; companion tabs with distinct IDs remain distinct even when titles match.
- Registered the local native host, packaged the development XPI, and documented that persistent installation requires Mozilla signing.

## Challenges and decisions

- The companion fixes awareness and identity, not authoritative PID ownership. PID mapping remains measured, confidence-scored inference.
- `about:processes` is an internal privileged Firefox page. Scraping its UI would be fragile and disruptive, so the supported Tabs API plus local native messaging was chosen.
- The extension was prepared but not silently loaded into Firefox; browser-extension installation requires an explicit confirmation step.
